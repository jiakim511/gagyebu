# 가계부 — 확인만 하면 끝

카드 결제 문자를 자동으로 받아서 목록에 쌓아두고, "확인" 버튼만 누르면 지출이 기록되는 개인용 가계부 웹앱입니다. 신한 체크카드 결제 알림(SMS) + 아이폰 단축어 자동화 + Google Apps Script를 통해 카드 결제를 반자동으로 수집하고, 현금·계좌이체는 앱에서 직접 입력합니다.

## 스크린샷 / 주요 화면

- **홈**: 이번 달 남은 예산, 최근 7일 지출 그래프, 오늘 쓴 내역
- **입력**: 키패드로 빠르게 입력하거나, "스벅 5600"처럼 한 줄로 입력하면 금액·가맹점·카테고리를 자동으로 인식
- **확인함**: 카드 결제 문자로 자동 수집된 대기 내역을 확인/확정, 카테고리 수정
- **리포트**: 주별(최근 8주) / 월별 지출 합계, 카테고리별 비중, 예산 수정, 전체 데이터 초기화

## 카테고리

식비 · 카페 · 교통 · 쇼핑 · 문화 · 연애 · 여행 (+ 수입: 급여/용돈/기타수입)

## 어떻게 동작하나요

이 저장소는 **앱 화면(프론트엔드)만** 담고 있고, GitHub Pages로 정적 호스팅됩니다. 카드 결제 문자를 받아서 저장하고 앱에 내려주는 **데이터 서버는 별도의 Google Apps Script**로 돌아갑니다. 둘이 분리된 이유와 전체 설치 방법은 [`SETUP_GUIDE.md`](./SETUP_GUIDE.md)에 처음부터 끝까지 정리되어 있습니다.

```
프론트엔드 (이 저장소, GitHub Pages)
        │  ①  JSONP로 대기 내역 읽기 (script 태그, CORS 없음)
        │  ②  no-cors POST로 "확정" 요청
        ▼
Google Apps Script 웹앱 (Code.gs)
        ▲
        │  아이폰 단축어 자동화가 카드 결제 문자를 POST로 전달
   신한카드 결제 문자 (SMS)
```

## 파일 구성

| 파일 | 역할 |
|---|---|
| `index.html` | 가계부 앱 화면 전체 (이 파일이 GitHub Pages로 서빙됩니다) |
| `manifest.json` | 웹앱 매니페스트 — iOS가 이 앱을 "제대로 설치된" 웹앱으로 인식하도록 도움 (`index.html`과 같은 폴더에 함께 올려야 합니다) |
| `Code.gs` | Google Apps Script 데이터 서버 (카드 문자 파싱·저장, 앱과의 동기화 API) |
| `SETUP_GUIDE.md` | GitHub Pages 배포 + Apps Script 배포 + 아이폰 설치까지 전체 가이드 |

## 설치 요약

1. Google Apps Script에 `Code.gs`를 붙여넣고 웹앱으로 배포 → 데이터 서버 주소(`.../exec`) 발급
2. 이 저장소에 `index.html`을 올리고 **Settings → Pages**에서 GitHub Pages 활성화 → 앱 주소 발급
3. 아이폰 Safari로 앱 주소 열고 "홈 화면에 추가"
4. 앱의 **확인함 → 연동 설정**에서 1번 주소와 토큰을 입력
5. 아이폰 단축어로 카드 결제 문자를 받으면 1번 주소로 자동 전달되도록 개인용 자동화 설정

자세한 스크린샷과 각 단계별 설명은 [`SETUP_GUIDE.md`](./SETUP_GUIDE.md)를 참고하세요.

## 데이터는 어디에 저장되나요

- 지출·수입 기록, 예산, 앱 설정: 이 앱을 연 기기의 **로컬 저장공간(localStorage)** 에만 저장됩니다. 다른 기기와 자동으로 동기화되지 않습니다.
- 카드 결제 문자로 들어온 "대기 중" 내역: Apps Script가 연결된 **구글 시트**에 저장되고, 확인함 탭에서 동기화해오면 위 로컬 저장공간으로 옮겨집니다.

## 보안/한계에 대한 참고

- 이 앱은 개인용 미니 프로젝트입니다. 인증은 `Code.gs`에 설정하는 `SECRET_TOKEN` 값 하나뿐이며, 계좌번호·비밀번호가 아니라 "카드 결제 문자 내용"만 오가는 구조라 위험도는 낮지만 완전한 금융보안 등급은 아닙니다.
- 아이폰 자동화 특성상 결제 즉시가 아니라 "문자 알림 배너에서 실행을 누른 시점"에 반영됩니다.
